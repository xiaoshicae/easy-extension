# 架构决策记录(ADR)

重要的、难以反悔的设计决策记在这里:背景、决定、理由、后果、否决的方案。一旦采纳就不改写,要推翻就写新的 ADR 并标注取代关系。

| 编号 | 标题 | 状态 |
|---|---|---|
| [0001](0001-v4-architecture.md) | 4.0 架构方向 | 已采纳 |

配套的设计草稿放在 [`doc/design/`](../design/)。

## 写法

```markdown
# ADR-NNNN:标题

状态(提议 / 已采纳 / 已取代) · 日期 · 适用范围

## 背景        为什么要决定;现状的数据
## 决策        做什么,一句话说清
## 理由与后果  好处、代价、什么情况下重新评估
## 否决的方案  为什么不选
```
